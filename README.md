# BMI Calculator 

A modern, responsive Body Mass Index (BMI) calculator built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **React Toastify**. This lightweight application allows users to quickly and effortlessly check their body mass index based on weight (lbs) and height (in), complete with real-time validation and visual feedback toasts.

##  Features

* **Precise Calculations:** Computes BMI instantly utilizing standard imperial formulas.
* **Instant Feedback:** Categorizes results into underweight, healthy weight, overweight, or obese ranges.
* **Interactive Notifications:** Integrated with React Toastify for clear status alerts.
* **Modern UI:** Styled seamlessly using Tailwind CSS for an optimal cross-device user experience.
